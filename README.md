# tándem studio — Landing

Landing page de tándem studio: socio estratégico y operativo de empresas, pymes y emprendimientos.

## Estructura

- `index.html` — Página completa, autocontenida (HTML + CSS + tipografías de Google Fonts inline).

## Uso

Abrí `index.html` en cualquier navegador, o serví la carpeta con un servidor estático:

```bash
python3 -m http.server 8000
# luego visitá http://localhost:8000
```

## Despliegue

Al ser un sitio estático de un solo archivo, se puede publicar en GitHub Pages, Netlify, Vercel o cualquier hosting estático apuntando a `index.html`.
